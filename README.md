# 倍音解析エディタ（初版）

お手本の単音 WAV を聴きながら、どの倍音が強いか、いつ立ち上がり、どのくらい残るかを調べるツール。

## 使い方

```bash
cargo run --release -- path/to/sound.wav   # 引数なしでも起動可（開始画面で WAV・ライブ入力・サンプルを選ぶ）
cargo run --release --example gen_test_tones   # 試験音を test_tones/ に生成
cargo test --release                            # 完成確認の音例を自動チェック
```

アプリの音を取り込むときは `.app` として起動する。macOS は「システムオーディオ録音」の許可を、Info.plist に用途の説明を持つアプリにしか求めないため、`cargo run` で直接起動するとエラーにならずに無音だけが届く（画面に「無音のまま」と出る）。

```bash
./scripts/bundle_macos.sh                  # target/release/HarmonicAnalyzer.app を作る（アドホック署名つき）
open target/release/HarmonicAnalyzer.app   # 初回に「システムオーディオ録音」の許可を求められる
```

許可は「システム設定 > プライバシーとセキュリティ > 画面収録とシステムオーディオ録音」で後から変えられる。

- **画面の構成**: 上の1行目にファイル・ライブ入力・再生・解析位置／再生位置・解析位置の「固定／再生に追従」・試聴の状態（「試聴: 550–770 Hz だけ」など）が常に出る。基音・窓長・表示・試聴フィルタの設定はその下に用途ごとにまとまり、幅が足りなければ折り返す（「設定を隠す」で畳める）。操作の一覧は「？ 操作方法」。
- **開始画面**: 音源を読み込む前は「WAV を開く」「ライブ入力」「サンプルで試す」が出る。サンプル（基音 220 Hz の4種）はアプリの中で作るので、配布用の `.app` でもファイル無しで開ける。
- **基音**: `A3`, `C#4`, `Bb2` などの音名、または `220` / `220 Hz`。A4 の基準とチューニング補正（±100 cent）で録音に合わせる。実際に使う周波数を常に表示する。「推定」を押すと、取り込んだ音（WAV・サンプル・ライブ入力の直近の音）から基音を推定し、最も近い音名とチューニング補正（cent）に設定する（YIN 法。音量のある区間の最大 40 か所で周期を求め、中央値を取る。範囲は 25 Hz〜4 kHz）。推定値と確からしさ（同じ周期が見つかった区間の割合）が横に出る。鐘のように倍音が整数倍でない音では、低めの値（共通の周期）が出ることがあるので、そのときは手で直す。
- **波形・スペクトログラム・倍音の時間変化**の3つは時間軸と解析位置（橙）・再生位置（緑）を共有する。どれかをクリックすると解析位置が移り、再生中ならそこから鳴り直す。橙と緑の縦線は近づくとカーソルが左右矢印になり、ドラッグで動かせる（シーク）。ドラッグ中は解析位置と各グラフが追従し、離したときに再生位置もそこへ移る。縦線から離れた所のドラッグは従来どおり表示の移動。Space で再生/停止。
- **倍音分布**（右）: 棒・一覧・凡例の名前をクリックすると、その倍音に注目する（詳細表示・「第k倍音の周り」の対象。表示の ON／OFF は変わらない）。注目中は時間変化のグラフでその倍音が太く手前に出て、ほかの線は半透明になる。同じ倍音をもう一度クリックすると注目を解除し、すべての線が元の濃さに戻る（起動時は注目なし）。時間変化のグラフに出すかは一覧のチェックで ON／OFF する。初期状態は第1〜第8倍音が ON、第9倍音以降は OFF。OFF にしても一覧に残る。「すべて OFF」「初期状態に戻す（1〜8）」で一括操作。範囲外の倍音はチェックできない。凡例は時間変化のグラフの上（グラフの外）に出る。解析位置の値は表と折れ線上の点で読め、棒と同じ値になる（同じ解析フレームを参照）。
- **倍音の範囲選択**: 倍音分布の棒の上を横にドラッグすると、その範囲にかかる倍音を選べる（確定前は白い帯と白枠で表示。見えている棒のうち範囲内のものだけが対象）。「選択のみ ON」（ほかは OFF）／「追加 ON」／「選択を OFF」で一覧のチェックへ反映する。Esc かキャンセルで取り消し。棒のクリックは従来どおり注目。
- **解析位置の固定／再生に追従**: 「再生に追従」では、再生中は再生位置のフレームを解析位置にする。グラフをクリック・ドラッグして解析位置を決めると「固定」に戻る。止めた位置はそのまま残り、最後まで再生した後に再生すると先頭から鳴る。
- **試聴フィルタ**: 「この帯域だけ聴く」と「この帯域を除く」を切り替えられる（スペクトログラム上ではそれぞれ水色・赤の帯）。範囲は Hz で入力するか、スペクトログラム上で Shift+ドラッグで指定する。帯の上下の線はそれぞれドラッグで動かせる（線の近くでカーソルが上下矢印になる）。「第k倍音の周り」で、注目中の倍音 ± 基音の半分に合わせられる。フィルタは再生音だけに掛かり、解析・グラフは元の音のまま。境界はなだらか（遷移幅は境界周波数の 3%、5〜100 Hz）で、境界ちょうどは −6 dB。
- **ライブ入力**: 「● ライブ入力…」で入力元のウィンドウを開き、入力元を選んでから「この入力元で開始」で始める。入力デバイス（マイク、オーディオインターフェイス、BlackHole などの仮想デバイス）の音を直近 5 秒ぶん保持し、約 70 ms ごとに解析し直して表示する（右端が現在、解析位置は常に最新のフレーム）。ウィンドウは「入力デバイス」と「アプリの音」のタブに分かれ、名前で絞り込める。入力は全チャンネルの平均。レベルメーターは直近のピーク（dBFS）。「■ ライブ停止」で、その時点の 5 秒がふつうの録音として残り、クリックで調べる・再生する・「WAV に保存…」で保存できる。ライブ中は再生と試聴フィルタは使えない（ハウリング防止）。初回は macOS のマイク使用許可を求められる。
- **アプリの音**（macOS 14.2 以降）: 入力元のウィンドウの「アプリの音」から、ブラウザなど特定のアプリが出している音だけを取り込める（● と「発音中」はいま音を出しているアプリで、先頭に並ぶ）。`.app` に属さないシステムの内部プロセスは「詳細」に畳んである。Core Audio のプロセスタップを使い、デジタルのまま受け取るので部屋の響きや雑音は入らない。アプリの音はそのままスピーカーからも聞こえる。ブラウザは別プロセス（Chrome なら Google Chrome Helper）から音を出すが、同じ `.app` の中のプロセスはまとめて取り込む。タブ単位では選べない（ブラウザ全体の音）。選んだ後に新しく音を出し始めたプロセスは入らないので、そのときは選び直す。Safari は音を WebKit の共通プロセスから出すため、一覧では「Safari」ではなく WebKit の名前で出ることがある。
- **レベル基準**: 0 dB = 振幅 1.0（フルスケール）の正弦波。録音全体・全倍音で共通。下限は −120 dB（無音はこの値で、異常値は出ない）。
- **範囲外**: 倍音の周波数がサンプルレートの半分以上なら「範囲外」とし、棒グラフ上では灰色の網掛け、読み取り欄では「範囲外」と表示する。範囲内で微弱な倍音は「≤ −120 dB（下限）」と表示する。

## 解析方法

- 4項 Blackman-Harris 窓（サイドローブ −92 dB）＋ 2倍ゼロ詰めの STFT。
- 窓長は既定で「基音の8周期以上を含む2のべき乗」（220 Hz/48 kHz なら 2048 = 42.7 ms）。手動で 512〜16384 を選べる。ホップは窓長の 1/8（64〜512 サンプル）。
- 第k倍音は k·f0 ± 10%·f0 の範囲でピークを探し、対数振幅の放物線補間で FFT ビンの間にある周波数の振幅を求める。範囲内に極大が無い場合（隣の成分の裾など）は k·f0 のビンの値を使う。

## 初版で決めた前提

| 項目 | 決定 |
|---|---|
| 対象 OS・形態 | macOS の単体アプリ（egui/eframe なので Windows/Linux でもビルド可能。日本語フォントは OS のものを読み込む） |
| WAV | PCM 8/16/24/32 bit 整数、32 bit 浮動小数点。チャンネル数は任意。解析は全チャンネルの平均、再生は元のチャンネルで行う |
| 音域 | 基音 10 Hz〜fs/2。解析する倍音は最大 512 本 |
| 時間分解能 | 上記の窓長・ホップ（自動 / 手動切替） |
| ライブラリ | eframe/egui + egui_plot（GUI）、cpal（再生）、hound（WAV）、realfft（FFT）、rfd（ファイル選択） |

## 開発用

`HA_SCREENSHOT=out.png HA_CURSOR=1.0 HA_SELECT=1,3 HA_FILTER=600-900 harmonic_analyzer file.wav` で、解析位置・表示する倍音・試聴フィルタ（`600-900:cut` で除去）を指定した画面を PNG 保存して終了する。`HA_WIDTH=1070`（ウィンドウ幅）、`HA_SAMPLE=3`（サンプルを開く）、`HA_PICK=7-9`（倍音分布の横軸で範囲選択し、確定前の状態にする）、`HA_SOURCES=1` / `HA_SOURCES=app`（入力元のウィンドウ）、`HA_HELP=1`（操作方法）、`HA_FOCUS=3`（注目する倍音）、`HA_ESTIMATE=1`（基音を推定）も使える。`HA_LIVE=1` を付けるとライブ入力を始め、約 2 秒後に保存する（`HA_LIVE=app:アプリ名` でアプリの音）。
